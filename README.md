# 임종주 · Jongju Lim

**Data Engineer · Project Lead | 데이터 수집 · ETL · 실시간 처리 · PM/PL**

엔씨소프트 데이터플랫폼 조직에서 15년 1개월간 데이터 수집, DW/DM·ETL과 실시간 데이터 서비스를 구축·운영한 데이터 엔지니어입니다. MONKEY(장애 모니터링 자동화 플랫폼)의 PM·PL과 NOW의 PL로 문제 정의, 요구사항 조율, 개발 리딩과 운영 개선을 수행했고, SBoard(경영 정보 포털)의 2회 대규모 개편을 주도했습니다. 해외 3개 지사 플랫폼 구축 참여와 Hive·SQL 사내 교육 경험을 보유하고 있습니다. 육군 장교 복무 경험을 바탕으로 책임과 협업을 중시하며, 기술을 직접 구현하면서 팀의 실행을 이끄는 리더 역할에 강점이 있습니다.

- **OASIS — 데이터 정보 포털**: 빌링·웹로그·인게임 로그 수집·정제, DW/DM·ETL 구축. 블레이드 앤 소울 론칭 시 40건 이상의 대시보드·통계 보고서 제공.
- **글로벌 데이터 플랫폼**: NCW·NCT·NCJ 해외 3개 지사 플랫폼 구축 참여. 공통 KPI·로그 기준과 다국어·타임존 요구를 반영한 DW·ETL 설계.
- **NOW**: Spark·Kafka 기반 실시간 로그 처리 및 Druid 조회 환경 구축 참여. 데이터 설계와 운영 대시보드 개발 리딩.
- **MONKEY — 장애 모니터링 자동화 플랫폼**: 데이터 적재 품질·장애 현황과 알림을 통합한 모니터링 플랫폼의 기획·개발·운영.
- **SBoard — 경영 정보 포털**: 경영 KPI 데이터 모델·API·웹 서비스 구현과 운영. 2회 대규모 개편 주도.
