제품을 만드는 방식

Data Engineering & Digital Products — 기획 · 개발 · 운영

모호한 요구를 사용자와 함께 정리하고, 원천 데이터부터 적재·집계·API·화면까지 따라가며 원인을 찾는 일을 즐깁니다. 현업과 개발자가 같은 문제를 이해하도록 설명하고, 피드백을 실제 동작과 사용 흐름으로 바꾸는 것이 강점입니다. 데이터가 발생하는 지점부터 API와 웹 화면까지 직접 개발한 경험을 바탕으로 고객 문제와 기술적 제약을 함께 이해하며 우선순위를 정합니다.

핵심 역량

  • 프로젝트 리딩: 사용자 인터뷰, 요구사항 분석, 기능 우선순위 조율, 화면 기획, 개발·운영과 후속 인력의 업무 정착.
  • 고객 경험: 메일 기반 장애 확인을 통합 화면·알림으로 전환하고, 실시간 게임 데이터의 필터·추적·플레이백 경험을 설계.
  • 웹 서비스 개발: Python·Django API, React·Next.js·TypeScript 화면, 인증·권한, 문의·알림과 운영 자동화.
  • 데이터 엔지니어링: 빌링·웹·인게임 로그 수집, DW/DM·ETL, SQL과 BI, Spark·Kafka 처리 및 Druid 조회 환경 설계.

최근 제품 개발

PLUTUS | 금융 지표·매매 분석 서비스

경제 지표 대시보드와 조건검색·종목 분석·매매일지를 연결한 웹 서비스를 개발해 공개했습니다. 로그인에 앞서 서비스 가치와 무료 이용을 안내하는 공개 소개 페이지를 마련했으며, 지표 기준일과 수집 시각·누락·지연을 구분하는 개선 과제를 정의했습니다. MCP·Report API·WordPress를 연결한 보고서 전달 흐름도 구현했습니다.

PLUTUS 매크로 · PLUTUS 매매 분석

TokenWatch | AI 모델 가격 비교

AI 모델의 API 토큰 가격·월 구독료·무료 이용 범위와 성능을 비교하는 웹 서비스를 개발·배포했습니다. 모델 버전과 요금 기준을 구분해 비교할 수 있도록 구성했습니다.
