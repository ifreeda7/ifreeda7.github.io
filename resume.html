임종주 데이터 엔지니어

엔씨소프트 데이터플랫폼 조직에서 15년 1개월간 데이터 수집, DW/DM·ETL과 실시간 데이터 서비스를 구축·운영한 데이터 엔지니어입니다. MONKEY(장애 모니터링 자동화 플랫폼)의 PM·PL과 NOW의 PL로 문제 정의, 요구사항 조율, 개발 리딩과 운영 개선을 수행했고, SBoard(경영 정보 포털)의 2회 대규모 개편을 주도했습니다. 해외 3개 지사 플랫폼 구축 참여와 Hive·SQL 사내 교육 경험을 보유하고 있습니다. 육군 장교 복무 경험을 바탕으로 책임과 협업을 중시하며, 기술을 직접 구현하면서 팀의 실행을 이끄는 리더 역할에 강점이 있습니다.

경력

엔씨소프트 | 2009.10.19–2024.12.15 | 15년 1개월

CTO 산하 데이터플랫폼실 데이터서비스개발팀 및 데이터프로덕트개발팀

핵심 역량

  • 프로젝트 리더십: MONKEY(장애 모니터링 자동화 플랫폼) PM·PL 및 NOW PL, 기능 우선순위·로드맵 수립, 유관 부서 요구 조율, 후속 개발·운영 인력 리딩과 사내 교육
  • 데이터 수집과 ETL: 빌링·웹로그·인게임 로그 수집 및 정제, 정기·비정기 적재, Informatica·SSIS·Python 기반 파이프라인 구축과 운영
  • 데이터 모델링과 SQL: Star/Snowflake 기반 DW·데이터 마트 설계, 차원 데이터 관리 자동화, Oracle·SQL Server 쿼리 및 테이블 설계·최적화
  • 실시간 데이터 처리: Spark·Kafka 기반 로그 수집·처리, Druid 기반 저지연 조회 환경 구축 참여, Hive 기반 데이터 활용
  • 품질 관리와 운영 자동화: 적재 품질·장애 모니터링, TV·웹 대시보드와 SMS·이메일 알림 통합, 운영자 피드백 기반 개선
  • 데이터 서비스 구현: Python·Django API, React·Next.js·TypeScript 기반 대시보드, Cognos·Tableau 기반 KPI 리포팅

리더십과 협업

MONKEY(장애 모니터링 자동화 플랫폼)의 PM·PL과 NOW의 PL로 사용자 요구사항을 개발 과제로 구체화하고, 우선순위와 로드맵을 정리하며 개발·운영을 리드했습니다. 전략기획실·사업부·운영자와 협업하고, 해외 플랫폼 구축 문서화와 사내 교육을 통해 지식을 공유했습니다. 육군 장교로 복무하고 중위로 전역한 경험을 바탕으로 책임과 보고·협업의 기본을 중시합니다. 기술을 직접 이해하고 구현하면서 팀이 목표를 실행할 수 있도록 이끄는 리더로 기여하겠습니다.

육군 장교 복무 | 2005.11–2008.11 | 중위 전역

  • 과제 정의와 실행 리딩: MONKEY(장애 모니터링 자동화 플랫폼) PM·PL로 운영자 요구를 정리하고 기능 우선순위·로드맵과 개발·운영을 리드했습니다.
  • 이해관계자 조율과 변화 관리: 전략기획실·사업부와 KPI·요구사항을 조율하고 SBoard(경영 정보 포털) 2회 개편을 주도했습니다.
  • 표준화와 지식 공유: 해외 지사 구축 문서화와 운영자 교육, Hive·SQL 사내 강사 경험을 보유합니다.

데이터 플랫폼 리더 관점

데이터 플랫폼 조직에서 원천 수집·ETL·DW/DM·집계·실시간 서비스와 운영을 이어온 경험을 바탕으로, 새로운 플랫폼을 시작할 때 비즈니스가 실제로 사용하는 데이터 제품과 지표를 먼저 정합니다. 그다음 수집·저장·정제·제공 경로의 정합성, 재처리, 모니터링, 소유자와 접근 권한을 함께 설계하는 접근을 제안합니다. 이는 향후 구축 방향이며 특정 클라우드·레이크하우스 제품의 직접 구축 실적으로 기재하지 않습니다.

초기 데이터 플랫폼 구축 참조 아키텍처와 90일 로드맵 · AJECT 기술블로그

2010–2016 | 데이터 모델링 · ETL 개발 · 대시보드 개발 및 운영

빌링·웹로그·인게임 로그 등 서로 다른 원천 데이터를 공통 지표와 통계로 제공해야 했습니다.

  • 요구사항 분석부터 원천 데이터 수집·정제, DW/DM 모델링, ETL 개발과 BI 제공까지 데이터 처리 흐름을 구축했습니다.
  • 정기·비정기 적재를 관리하고 데이터 품질 모니터링과 장애 대응을 수행했습니다. Oracle·SQL Server 기반 쿼리 최적화와 테이블 설계도 담당했습니다.
  • 게임 XML 구조를 활용해 차원 데이터를 자동 갱신하는 시스템을 Python·Java로 개발했습니다.

성과: 블레이드 앤 소울 2012년 론칭 데이터 담당자로 참여해 40건 이상의 대시보드·통계 보고서를 기한 내 제공했습니다.

  • NCW·NCT·NCJ의 데이터 플랫폼 구축에 참여해 현지 서버·스토리지·DB 요구사항을 조사하고 아키텍처 및 도입 문서를 작성했습니다.
